Behavior and model notes

This browser demo is an educational JavaScript model of the supplied synchronous FIFO specification. It does not execute the SystemVerilog RTL, run UVM, or measure verification coverage.

Operations use the occupancy before the rising edge. At empty, simultaneous read/write accepts only the write and reports underflow. At full, it accepts only the read and reports overflow. In between, both succeed and occupancy stays unchanged.

Almost-full means 7 occupied words; almost-empty means 1. ACK, overflow and underflow describe the latest edge. This model initializes and clears these status flags on reset. Reset is asynchronous, clears pointers, occupancy and data_out, and retains memory bits. The output holds its previous value until a successful read or reset.

The earlier report screenshots contain implementation differences, including almostfull at depth − 2 and combinational underflow. This page intentionally demonstrates the specified FIFO behavior rather than reproducing those differences.
